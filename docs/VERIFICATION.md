## Живая интеграция — ручной checklist

Требуется отдельный авторизованный MAX-инстанс и аккаунт получателя. Эти пункты **не проверены на живом сервисе**:

- [ ] Проверить `apiUrl` и доступность API из браузера (включая CORS).
- [ ] Настроить входящие уведомления, пустой webhookUrl, одного потребителя очереди.
- [ ] Войти и проверить создание чата по реальному телефону.
- [ ] Отправить текст и убедиться, что он появился у получателя в MAX.
- [ ] Ответить в MAX и убедиться, что ответ появился один раз в нужном чате.
- [ ] Проверить статусы доставки при включённом outgoingWebhook.
- [ ] Проверить ограничения тарифа и приватность поиска по телефону.

Публичное размещение зависит от выбранного хостинга. Для публикации достаточно содержимого `dist/`; тестовые страницы в него не попадают.
