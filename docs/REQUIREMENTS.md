# Требования и план / Requirements and plan

Тестовое задание: интерфейс обмена текстовыми сообщениями в MAX через GREEN-API. Срок выполнения — 5 дней.

## Обязательные

- React, интерфейс по образцу веб-версии MAX, минимум функций.
- GREEN-API для MAX: ввод idInstance/apiTokenInstance, создание чата по телефону.
- Только текст: SendMessage; ответы через ReceiveNotification + DeleteNotification.
- Полный сценарий: подключиться → создать чат → отправить → увидеть ответ из MAX.
- Strict TypeScript, отсутствие any/@ts-ignore, доступность и адаптивность.
- Состояния загрузки, ошибок, пустых данных, валидация; отмена запросов и защита от двойной отправки.
- Unit/component tests; lint, typecheck, test, build; чистая установка и браузерная проверка.
- README RU/EN, Conventional Commits.

## Желательные

- Публичный URL, скриншоты/видео. E2E по выбору.
- Покрытие критической логики близко к 100%.

## Неоднозначные

- Макет за авторизацией: воспроизводим компоновку мессенджера, не заявляем pixel-perfect.
- apiUrl отсутствует в списке полей ТЗ, но необходим по документации: отдельное поле из кабинета.
- Номер MAX не равен chatId: используем CheckAccount (РФ/РБ согласно документации).
- История/хранение не заданы: состояние сессии в памяти; без загрузки старой истории.
- Автоматические тесты используют mock HTTP; живой smoke test требует авторизованного MAX-инстанса.

## Этапы реализации

1. React + Vite + TypeScript strict + Tailwind CSS; FSD; ESLint/Prettier/Vitest/Testing Library.
2. shared/api — HTTP-клиент; entities/chat — модель данных; features/messaging — последовательный polling.
3. features/connect и features/messaging — сценарии; widgets/messenger — компоновка; pages/messenger — сессия; app — инициализация.
4. Тесты контрактов/валидации/повторов/отмены и пользовательских сценариев.
5. Чистая установка, проверки, браузер, README и итоговый аудит.
